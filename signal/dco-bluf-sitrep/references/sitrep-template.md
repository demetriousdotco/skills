# SITREP-NN.md Template

The report. Compiled purely from LOG.md + 03-ANALYSIS.md — if it isn't in those docs, it doesn't go in. Readable in a few minutes; the plan fits one screen; depth lives in LOG.md (link, don't inline). Omit empty sections. Zero judgment language, zero pleasantries.

```markdown

[date] · Run [N] · Prepared by dco-bluf-sitrep · Full story: LOG.md

**BOTTOM LINE: [one sentence — overall temperature + what needs the reader.
e.g. "Recoverable. Three loops you owe, two you're owed, one contradiction blocking launch."]**

[Situation paragraph — 2–4 sentences, fire-in-the-main-hall pattern: what this
situation is, where it stands, what it's costing, state of handling.]

- Closed: … · New: … · Resolved: …  [L-IDs]

## Rules

- **Order is fixed:** bottom line → situation → delta (chained) → state of play → open loops by person → contradictions → plan → unknowns. Importance before information.
- **Open loops group by person**, reader first — the section must map one-to-one onto "who do I contact." Ages in days, oldest first within each person.
- **Plan actions** follow the plan doctrine in ledger.md: traceable, concrete (person + verb + thing), prioritized (blocking contradictions → oldest reader-owed → nudges → verifications → rest), one screen.
- **Every line cites L-IDs or C-IDs.** The reader can drop from any claim straight into the ledger.
- **Statuses are honest:** "claimed done — unverified" is a real status and appears as such. Never round up to "done."
- **Neutral phrasing for the reader's own debts** — same format as everyone else's, no softening, no scolding.
- Numbers, dates, names exact or absent.

## Delivery + drill-down

Deliver SITREP-NN.md, point to LOG.md as the catch-up read ("the whole story in order, ~[N] entries"), then stand by for questions:

- Answer strictly from the ledger and acquired sources, with L-IDs.
- Not in the material → "Not in the material." Offer labeled outside knowledge only if useful: "Outside the sources, if you want it: …"
- Significant drill-down findings → append to the ledger as entries so chained runs keep them.
- Asked to draft the reply/email itself → one line: that's beyond this skill's post; the plan says who and what, the writing is theirs. Then keep helping from the material.
```

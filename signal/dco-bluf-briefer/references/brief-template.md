# SITREP.md Template

The brief. The only thing the reader reads. Compile purely from the working docs — if it isn't in a working doc, it doesn't exist. ~350 words / one screen, ceiling (see triage.md for cut order). Omit empty sections entirely. Zero pleasantries, zero preamble beyond the template itself.

```markdown
# SITREP: [Brief Slug]
[date] · Material from: [sender] · Prepared by dco-bluf-briefer

**BOTTOM LINE: [verdict line — one sentence.]**

**Your question — "[standing question]":** [the explicit answer, 1–2 sentences.]

[Situation paragraph — 2–4 sentences, fire-in-the-main-hall pattern.]

## Act now
- [item, 1–2 sentences] [pointer]

## Decisions needed from you
1. [item — framed as the actual choice: "Approve X?" / "A or B?"] [pointer]

## Problems / risks
- [item] [pointer]

## Asks buried in the material
- [item — what they want from you, where it was hiding] [pointer]

## Deadlines
- [date — what it gates] [pointer]

## Can wait
- [one line each] [pointer]

## FYI
- [one line each] [pointer]

## Known unknowns
- [unacquired source — what it might contain] 

## Also logged
[Only if the ceiling forced cuts: bare one-liners.]

---
Sources: [list, from 01-SOURCES.md]. Ask me for depth on any item — answers come with pointers, from the material only.
```

## Rules

- **Order is fixed.** Bottom line → standing question → situation → Act now → Decisions → Problems → Asks → Deadlines → Can wait → FYI → Known unknowns. Importance before information, always.
- **Pointers on every item**, same formats as the digest: `[loom ~11:20]`, `[proposal.pdf p.4]`, `[email 07/09]`.
- **Decisions are framed as decisions** — a question the reader can answer in one word, not a topic ("Approve the $450 stock-photo license?" not "Regarding photography licensing…").
- **Buried asks name their hiding place.** "Wants the final domain name — mentioned in passing at [loom ~11:20]" — the hiding place is proof of the skill's value and tells the reader where to verify.
- Numbers, dates, and names are exact or absent. No "around", no "I believe".
- If a dco-great-feedback package was among the sources, its `hunch` items carry the tag into the brief: "[hunch — sender couldn't fully articulate]".

## Drill-down Q&A (after delivering the brief)

- Answer strictly from the acquired material, with pointers, in the same clipped register.
- Not in the material → say exactly that: "Not in the material." If general knowledge would help, offer it explicitly labeled: "Outside the sources, if you want it: …"
- Log significant findings to 02-DIGEST.md's drill-down log so resume keeps them.
- Never drift into drafting replies to the sender — out of scope, say so in one line if asked.
```

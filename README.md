# AI skills for knowledge work

**Free Claude skills for entrepreneurs and professionals whose work moves through other people.**

Everyone uses AI to produce *more* — more emails, more documents, more Looms. Almost nobody uses it to make any of that *clearer*. This library is the counter-move: skills that kill noise instead of adding to it.

Built by [Demetrious Reed](https://demetrious.co) — thinker & maker. Free, no gates, no tracking. Every skill is plain, readable markdown: open any folder here and read exactly what your AI will do before you install it.

## Install (one file, one drag)

1. In Claude: **Settings → Capabilities → Code execution** — switch it on.
2. Download a `.skill` file above and **drag it into any Claude chat** → hit *Save skill*.
3. Just talk. Skills trigger themselves — *"brief me on this"*, *"help me send feedback on this draft"*, *"I need a sitrep."*

Alternate paths, Claude Code install, and troubleshooting: [docs/install.md](docs/install.md)

## Why BLUF?

Two of these skills carry the name. **BLUF — Bottom Line Up Front** — is military briefing doctrine: the verdict first, the detail after, because the reader may only get ten seconds. Everything in this library briefs you like you're the general. The full philosophy: [docs/philosophy.md](docs/philosophy.md)

## Privacy

Skills run inside **your own** Claude account. Nothing phones home, nothing is collected, there is no telemetry — this is a folder of markdown instructions, and you can read every line of it right here.

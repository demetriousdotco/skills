# FAQ

**What's a Claude skill?**
A folder of instructions Claude reads when the moment matches. One file, one drag, installed. No code runs on your machine — it's a playbook your AI follows.

**Does this cost anything?**
The skills are free. You need a Claude account with code execution enabled — that's it.

**Is my data shared anywhere?**
No. Skills run inside your own Claude. Nothing phones home, there's no telemetry, and the source of every skill is in this repo — read every line before you run it.

**Can I share these?**
Yes — forward the `.skill` file, this repo, or the pages at [demetrious.co](https://demetrious.co). Skills are per-account, so each person installs their own copy. MIT licensed.

**Can I use these at work / commercially?**
Yes. MIT means yes.

**Do they work in Claude Code?**
Yes — unzip into `~/.claude/skills/`. See [install.md](install.md).

**How do updates work?**
Each [release](https://github.com/demetriousdotco/skills/releases) is a full snapshot of the current library. The `releases/latest/download/...` links always serve the newest version of every skill. Reinstall = the same drag.

**Something's broken / I have an idea.**
Open an [issue](https://github.com/demetriousdotco/skills/issues). Real usage reports make the skills better.

**Who made these?**
[Demetrious Reed](https://demetrious.co) — a freelance strategist and designer who got tired of watching good work die in bad communication. More skills coming; same theme, always: knowledge work, less noise.
